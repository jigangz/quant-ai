## Context

Quant AI has been developed through Phase 1 (K-line charts, indicators, Screener), Phase 2 (strategy system, paper trading), and Phase 2.5 (cloud-native infra: Redis, SQS/SNS, Lambda, Kafka). The backend is substantial (133 Python files, 17,586 LOC) but has never been end-to-end verified as a working product:

- **Tests can't run locally** (missing venv dependencies)
- **CI skips contract tests**, marks cache tests as optional, excludes `TestStrategiesAPI`
- **Frontend is missing 3 pages** (Screener, Strategy, Trading) that the backend already supports
- **7 API modules have zero test coverage**
- **Legacy hardcoded paths** (`artifacts/model.joblib`) in predict/explain services
- **UI is raw** — inline styles, no CSS framework, raw JSON display, no React Router

Goal: Make Phase 1–2.5 production-grade — all tests pass, CI green, all pages functional, demo-ready UI.

## Tech Decisions

| Decision | Choice | Reason |
|----------|--------|--------|
| CSS framework | Tailwind CSS | Lightweight, works with existing setup, no component lock-in |
| Routing | react-router-dom | Standard, replaces manual page state |
| Chart library | Keep Lightweight Charts (existing) | Already integrated, TradingView compatible |
| Test fixtures | SQLite in-memory | No external DB needed for CI |
| Dark theme | Yes | Finance apps convention, looks professional |
